# 使用说明

## 1. 从对话开始

打开“对话”，在输入框描述任务，也可以直接粘贴内容链接。顶部 Tab 用于选择 Agent、采集、拆解、创作或热点场景；发送第一条消息后，欢迎区会收起，为结果留出更多空间。

输入框支持：

- 添加附件；
- 引用采集库、拆解库或创作库中的知识；
- 同时选择多个技能，并从输入框中的标签移除技能。

任务创建后可在右上角任务中心查看进度。完成的对话会出现在左侧历史记录中，支持恢复、重命名和删除。

## 2. 管理采集库

采集库包含单篇采集、关键词采集库、博主内容库和博主信息库。默认 sandbox Provider 会生成可重复的示例结果，不请求真实平台。

真实采集需要部署者提供合规数据源和 API 凭据。请勿采集无权使用的内容。

## 3. 内容拆解与创作

在拆解库查看内容结构、钩子、受众和情绪等维度。可以从拆解结果继续发起创作，在创作库查看版本、引用关系和采用状态。

Mock 模型用于演示工作流，不代表真实模型质量。启用外部模型后，每次调用可能产生费用。

## 4. 封面设计

封面设计默认返回模拟方案。接入真实图片 Provider 前，请确认素材权利、费用上限和内容安全策略。

## 5. 飞书同步

默认飞书 Provider 为 sandbox，只展示绑定与同步流程。真实 OAuth 和多维表格写入需要应用管理员配置回调地址、权限范围和目标数据表，并显式开启真实写入。
